# Развертывание стека мониторинга Zabbix с удаленным доступом через ngrok

Репозиторий содержит конфигурационные файлы для быстрого развертывания системы мониторинга Zabbix 7.0 LTS на базе СУБД PostgreSQL в Docker-контейнерах, с автоматическим пробросом веб-интерфейса и SSH-доступа к хосту через утилиту ngrok.

## Архитектура стека

Стек разворачивается в изолированных Docker-сетях:
* `zbx-backend`: для внутренней связи между сервером Zabbix, веб-интерфейсом и базой данных PostgreSQL.
* `zbx-frontend`: для связи веб-интерфейса с контейнером ингресса ngrok.
